OPTIMIZE THE CMAC MULTIPLIER WITH A STRUCTURAL WALLACE TREE

What is a Wallace Tree

A Wallace tree is a parallel reduction structure that compresses multiple operands down to two values (sum and carry) using layers of carry-save adders. Unlike sequential addition where carries propagate through each bit position, Wallace trees use parallel stages where each layer independently reduces the number of operands. Each reduction stage processes groups of inputs using carry-save adders, outputting fewer partial results. This process repeats across multiple layers until only two values remain, which can then be added with a final carry-propagate adder.

The key advantage is depth: reduction happens in logarithmic stages rather than linear time, since all bit positions are processed simultaneously without waiting for carry propagation.
