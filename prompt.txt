REPLACE CSA TREE WITH STRUCTURAL WALLACE TREE

The CMAC multiplier currently uses NV_DW02_tree modules for carry-save adder tree reduction. Replace these with structural Wallace tree implementations for better synthesis predictability and performance.

Your Task

Study the existing code to identify where NV_DW02_tree is used and what interface it provides. Implement structural Wallace tree modules that provide the same functionality.

File Organization

Place your Wallace tree implementation files in the sources/vmod/nvdla/cmac/ directory (same location as the multiplier you're modifying). This follows NVDLA's organization principle where application-specific modules stay with their parent components, while vmod/vlibs/ is reserved for generic, parameterized library components.

Create as many separate files as you need for your implementation.

Your Wallace trees should match the interface of what they're replacing - same inputs, same outputs, just different internal implementation.

Requirements

The complete NVDLA source code is provided for context. Study the code to understand:
  - What needs to be replaced
  - What the interface requirements are
  - How your implementation integrates with the existing design

Your implementation must be functionally equivalent to the original - all operating modes must continue working correctly.
