OPTIMIZE THE CMAC MULTIPLIER WITH A STRUCTURAL WALLACE TREE

A Wallace tree reduces multiple operands to two values (sum and carry) using carry-save adders organized in parallel reduction stages.

Your Task

The CMAC multiplier's carry-save reduction stage uses a generic compressor component. Study the multiplier source to understand the reduction topology, then replace that component with a hand-crafted Wallace tree implementation using the modules below.

Requirements

Your implementation must:
  - Produce correct arithmetic results across all operating modes (INT8 dual-lane, INT16, FP16)
  - Use structural instantiations (no behavioral loops)
  - Maintain the same multiplier interface (no new external ports)

Required Modules

Implement these modules with the exact interfaces specified below. Place all your Verilog files in the sources/vmod/nvdla/cmac/ directory.

  Module: NV_NVDLA_CMAC_CORE_csa32
    Parameter: WIDTH
    Inputs:  in0[WIDTH-1:0], in1[WIDTH-1:0], in2[WIDTH-1:0]
    Outputs: sum[WIDTH-1:0], carry[WIDTH-1:0]

  Module: NV_NVDLA_CMAC_CORE_csa42
    Parameter: WIDTH
    Inputs:  in0[WIDTH-1:0], in1[WIDTH-1:0], in2[WIDTH-1:0], in3[WIDTH-1:0], cin[WIDTH-1:0]
    Outputs: sum[WIDTH-1:0], carry[WIDTH-1:0], cout[WIDTH-1:0]

These exact module names and port names are required for testing.
