OPTIMIZE THE CMAC MULTIPLIER WITH A STRUCTURAL WALLACE TREE

The Problem

The CMAC multiplier uses generic NV_DW02_tree modules for carry-save addition (CSA) tree reduction. Replace these with an explicit structural Wallace tree implementation for better performance and synthesis predictability.

What is a Wallace Tree

A Wallace tree reduces multiple numbers down to two values (sum and carry) in logarithmic depth using carry-save adders. Unlike sequential addition with ripple carries, Wallace trees use parallel reduction stages where all bit positions work simultaneously without waiting for carries to propagate. Each stage compresses groups of inputs down to fewer outputs using carry-save adders, repeating until only two values remain.

Your Task

Replace the NV_DW02_tree instances in the CMAC multiplier with structural Wallace tree implementations. Study the NVDLA source code to understand how many instances exist, what they do, their interfaces, and how data flows through the multiplier's three operating modes (INT8, INT16, FP16).

Requirements

Your implementation must:
  - Produce functionally equivalent outputs to the original NV_DW02_tree
  - Support all three operating modes (INT8, INT16, FP16)
  - Use structural instantiations (no behavioral loops)
  - Maintain the same multiplier interface (no new ports)
  - Replace all NV_DW02_tree instances completely

File Organization and Module Names

Place your implementation files in sources/vmod/nvdla/cmac/ directory. Create separate module files for each component.

For CSA compressor building blocks, use these exact module names and port structures:

NV_NVDLA_CMAC_CORE_csa32 (3-to-2 CSA compressor)
  - Parameter: WIDTH
  - Inputs: in0[WIDTH-1:0], in1[WIDTH-1:0], in2[WIDTH-1:0]
  - Outputs: sum[WIDTH-1:0], carry[WIDTH-1:0]
  - Function: 3 inputs → 2 outputs (sum + carry = in0 + in1 + in2)

NV_NVDLA_CMAC_CORE_csa42 (4-to-2 CSA compressor)
  - Parameter: WIDTH
  - Inputs: in0[WIDTH-1:0], in1[WIDTH-1:0], in2[WIDTH-1:0], in3[WIDTH-1:0], cin[WIDTH-1:0]
  - Outputs: sum[WIDTH-1:0], carry[WIDTH-1:0], cout[WIDTH-1:0]
  - Function: 5 inputs → 3 outputs with independent carry chain

Both CSA compressor modules are required.

For Wallace tree modules that instantiate these CSA blocks, use the pattern NV_NVDLA_CMAC_CORE_wallace_* (you choose the suffix). These Wallace tree modules should instantiate the CSA building blocks to create the complete reduction tree.
